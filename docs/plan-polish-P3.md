## 1. 阶段一：打磨完善（Phase 1）

解决 P3 一、二期遗留的小问题，提升整体工程质量与用户体验，作为 P3 三期的稳固基础。

### 1.2 打磨项清单

| # | 打磨项 | 类型 | 复杂度 | 说明 |
|---|---|---|---|---|
| **M-1** | `config init` 交互式向导 | 功能 | 中 | P3-E2 的交互式部分未实现，当前只有配置节扩展。升级为自动检测 + 交互式引导 |
| **M-2** | `new` 向导执行参数 bug 修复 | 修复 | 低 | `new` 中 `GenerationRequest` 未用 merged 配置，导致 BPM/和弦/小节用户输入不生效 |

```
M-8（提交 .gitignore）→ M-2（修复 new bug）→ M-3（灵感库 chords）
```

### 1.4 打磨退出标准

- 全量测试全绿，覆盖率 ≥ 90%
- `new` 向导用户输入全部生效

- 文档与实现一致

## 2. 阶段二：P3 三期（Suno 衔接）

### 2.1 目标

把"本地生成 → 手动上传 Suno"的断点补齐，提供打包 + 清单辅助，并调研 Suno API 可行性。

### 2.2 P3 三期需求

| # | 需求 | 类型 | 复杂度 | 说明 |
|---|---|---|---|---|
| **P3-B2** | `export suno --batch` 导出包 | 功能 | 低 | 批量导出 10-30s 片段 + metadata 打包成 zip/目录 |
| **P3-B3** | 上传清单生成 | 功能 | 低 | 生成 CSV/JSON 清单，指引用户在 Suno 逐个上传 |
| **P3-B1** | Suno API 集成调研 | 研究 | 中-高 | 调研 Suno 是否开放官方 API；若开放则集成自动上传 |

### 2.3 实现顺序

```
P3-B2（打包）→ P3-B3（清单）→ P3-B1（API 调研）
→ 全量回归 → 提交 v0.5.0
```

### 2.4 退出标准

- `export suno --batch` 产出打包目录 + metadata
- 上传清单 CSV/JSON 可被用户直接使用
- Suno API 调研结论明确（开放/不开放/第三方方案）
